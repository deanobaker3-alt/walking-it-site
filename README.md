# Walking IT

Real IT problems, one step at a time. Four free, interactive walks for IT new starters:

- **Ticketwalk**: helpdesk tickets, from password resets to "the internet's down"
- **Cloudwalk**: Microsoft 365 and Entra ID
- **Packetwalk**: networking, from DNS to VPNs
- **Breachwalk**: cyber attacks played out step by step

Live site: https://deanobaker3-alt.github.io/walking-it-site/

Also by Dean Baker: [Hump Day Hack](https://deanobaker3-alt.github.io/hump-day-hack/), a new IT case every Wednesday.

This repo is the published copy of the site. It's built automatically, so changes made here directly will be overwritten.
